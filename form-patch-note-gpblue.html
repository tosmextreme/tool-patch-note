ตั้งค่า Google OAuth Client ID
ทำครั้งเดียว — บันทึกอัตโนมัติในเบราว์เซอร์
📋 วิธีสร้าง Google OAuth Client ID
1
เปิด console.cloud.google.com → New Project → ตั้งชื่อ เช่น GP-Blue Form
2
APIs & Services → OAuth consent screen → เลือก External → กรอกชื่อ App → Save
3
Credentials → + Create Credentials → OAuth client ID → Application type: Web application
4
Authorized JavaScript origins → เพิ่ม URL หลักของไซต์ เช่น https://yourdomain.com (ไม่มี path ต่อท้าย)
5
คลิก Create → Copy Client ID (ลงท้ายด้วย .apps.googleusercontent.com) → วางด้านล่าง
⚠️ Client ID ไม่ถูกต้อง — ต้องลงท้ายด้วย .apps.googleusercontent.com
💡 Client ID จะถูกเก็บใน Browser (localStorage) บน Browser นี้เท่านั้น — สมาชิกคนอื่นต้อง Setup ที่ Browser ของตัวเอง
